# Handoff Summary

## Current Objective
State the active goal in 2–5 sentences. Include broader context only if it
directly affects next actions.

## Successor Focus

## Working State
Describe what currently exists and what is known to work. Include concrete
artifacts (files, modules, commands, systems).

## Plans

deferred, superseded, or done. Only include plans that still matter.

## Observations

## Actions Taken

## Commits / Change History

workflow rules, test strategy decisions, and do-not-repeat lessons.

## Open Questions
Only include unresolved questions that materially affect next steps.

## Next Best Step
Provide ONE concrete next action that can be executed immediately without
additional planning.

## Context to Preserve Verbatim
Include short exact snippets ONLY when wording matters: commands, error
messages, config fragments, API contracts, and user constraints.
