# Reference Material

Vendored external material used in TOAS research and design. These documents
preserve their authors' claims; inclusion does not make them TOAS requirements
or evidence of shipped behavior.

Keep each source in its own directory with a pinned version, attribution,
license, upstream links, and a description of local conversion changes. Keep
TOAS interpretation in `docs/notes/`, linked in both directions. Preserve source
wording rather than silently correcting or adapting it.
