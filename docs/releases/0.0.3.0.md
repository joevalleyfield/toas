# TOAS 0.0.3.0

Release date: 2026-08-30

## Summary

This release turns the transcript frontier into a more capable, explicit action
surface. It adds durable concept-graph compaction, ordered multi-action plans,
language-specific executable fences, and grant-aware execution policy while
keeping direct user authority distinct from model-addressable capability.

## Highlights

- Added transparent, durable concept-graph artifacts to compaction and
  successor sessions, including a focused handoff prompt and concept-aware
  continuation naming.
- Added canonical action-plan discovery and durable compound tool-request
  records, so ordered frontier actions retain their intent and provenance.
- Added executable Markdown fence lanes for Bash, Python, PowerShell, JSON
  callables, and configured generic interpreters, with explicit activation and
  runtime/cwd configuration.
- Added grant evaluators and environment-policy resolution so executable
  interpreters and shell grants apply consistently across runtime paths.
- Improved tool ergonomics with read-file line controls, restored write-file
  support in the default seed prompt, and indentation preservation in edits.

## Notable Fixes

- Preserved shell-command source positions after inert projected results.
- Preserved partial search results when a subprocess times out and handled
  missing subprocess output safely.
- Preserved host paths across Windows runtime boundaries and removed the
  platform-sensitive default-session symlink fixture.
- Tightened assistant turn boundaries, seed-envelope projection, and compact
  marker handling for more predictable continuation behavior.

## Deferred

- Package publication, signing, distribution channels, and hosted CI remain
  outside the current lightweight tagged-release process.
- Real Windows runtime verification remains an open platform-validation task;
  the fixes in this release improve portability but do not claim that broader
  validation is complete.
