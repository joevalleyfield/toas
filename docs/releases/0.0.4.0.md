# TOAS 0.0.4.0

Release date: 2026-10-16

## Summary

TOAS 0.0.4.0 introduces the **State-Shaped Execution & Protocol Tech Preview**,
adds canonical model endpoints and named target workflows, introduces modular
runtime help and topic facets, strengthens frontier policy and branch projection,
and enhances tool execution ergonomics with batch try-all modes, soft bounds,
and near-literal preview inspection.

## Tech Preview: State-Shaped Execution & Frontier Protocols

> [!NOTE]
> State-shaped execution and its frontier protocols are included in this
> release as an active **technology preview**. The underlying runtime machinery,
> transition validation, and inspection affordances have landed and are ready
> for experimentation, but we do not yet recommend adopting state-step as the
> primary operator work-surface.

Key capabilities landed in this preview:
- Typed state transcripts with active state editing and explicit user-intent
  `user_tool_calls`.
- Structured state protocol composition with explicit tool argument type
  signatures, definitions, and guidance.
- State-step inspection affordances:
  - `toas step --preview-request` to inspect request messages without calling the model.
  - `toas step --preview-request-pretty` for near-literal, formatted request inspection.
  - `toas step --preview-response` to inspect unaltered model responses.
  - `/infer-from` affordance for multi-state sequence inference.
- Protocol reference handles, bounded slice references, and reference overlays.
- Transition lifecycle hardening: proposal scoping to the active frontier,
  invalidation of stale proposals, and validation diagnostics on invalid generation.
- User-facing terminal reporting channel with completion projection in transcripts
  and CLI output.

## Highlights

### Model Endpoints & Named Targets
- Canonicalized endpoint and target vocabulary across configuration, runtime,
  and CLI commands (`/endpoint`, `/endpoints`, `/model`, `/models`).
- Added structured model catalog inspection, freshness tracking for catalog
  refreshes, and explicit observation modes (`live`, `known`, `refresh`).
- Added interactive authoring workflows for endpoints and model targets,
  including automatic inference of unambiguous endpoint defaults and promotion
  of known models to targets.
- Hardened target resolution with fail-closed behavior on unavailable targets
  and keyed table storage.

### Runtime Help & Topic Guidance
- Factored help topic facets across config precedence, execution boundaries,
  extraction, and generation.
- Integrated runtime guidance assets and curated topic sources directly into
  `/help` and `/config show` overviews.
- Rationalized navigation hints and clarified help topic feedback.

### Frontier Resilience & Branch Policy Projection
- Added lossless fence retry materialization and assistant source reference
  preservation across recovery paths.
- Added branch-projected policy programs: workspace scope, command context,
  model selection, and direct branch grants/config projection.
- Hardened executable fence execution by applying transcript environment
  modifiers and preserving inherited execution PATH.
- Separated direct-user command timeout handling from recovery mechanisms.

### Tool Ergonomics & Execution Modes
- Added batch tool non-fatal execution mode (`continue_on_error` / try-all)
  across runtime, protocol, and projection.
- Added `read_file` clean EOF truncation and soft line bounds to preserve
  read ergonomics on large files.
- Added near-literal preview request inspection in the CLI.
- Isolated subprocess standard output streaming to prevent `TOAS_STREAM_STDOUT`
  from leaking into tool child processes.

## Notable Fixes

- Preserved referenced source spans and staged plan source during recovery flows.
- Preserved kwargs wrapper compatibility and configuration for injected controls.
- Hardened partial search result handling when subprocesses time out.
- Guarded against malformed generation overrides.
