# TOAS 0.0.5.0

Release date: 2026-11-08

## Summary

TOAS 0.0.5.0 adds standard agent skills, bounded multi-turn stepping, richer
transcript telemetry, and configurable tool-output spillage. It strengthens
branch-local policy, executable grants, model setup, and editor integration.

## Highlights

- Discover and activate workspace, global, and bundled skills, with explicit
  precedence and shadowing. Specialize skills and distill prompts into companion
  scripts; bundled skills cover code review, task recording, and jj scratch work.
- Run bounded multi-turn steps with quiescence termination and Vim count-prefix
  mappings. Assistant turn handles, configurable namespaces, and dense progression
  make transcript turns easier to identify and follow.
- Inspect turn execution status and cumulative token telemetry in transcripts,
  with adaptive history-calibrated token estimates.
- Configure tool-output spillage thresholds, preview extractors, duplicate-line
  elision, line-width caps, and a preview byte backstop.
- Use language-native write materialization, composable executable fences, fence
  I/O channels, artifact redirection, and direct state tool-to-artifact capture.
- Inspect unified namespaced policy and provenance. Branch-isolated policy
  resolution and intra-turn mutation propagation keep effective grants current.
  Executable authorization now has a shared seam and discoverable user policies
  with standard matchers; the CLI adds command harvesting and policy scaffolding.
- Select discovered models without manually creating targets, couple generation
  settings and rate limits to targets/endpoints, and inspect configuration-load
  diagnostics. Session continuation supports configurable names and custom grants.
- Operator commands now use a declarative registry and domain modules, with
  presentation templates separated from command execution.

## Notable Fixes

- Prevent false quiescence during bounded stepping and preserve per-turn stream
  state and multi-turn Vim run-region boundaries.
- Parse transcript markers with fence awareness, preserving contained examples.
- Preserve literal shell arguments without Python glob expansion; improve scalar
  argument coercion and shell diagnostics.
- Improve apply_patch atomicity, indentation healing, and unified-diff diagnostics;
  allow read_file max_lines together with end_line.
- Preserve endpoint configuration through transcript reconstitution and send
  authorization headers for OpenAI model probes.
- Normalize spilled CRLF content and MSYS Vim paths, restore native Windows
  verification, and reconcile streamed transcript telemetry with canonical output.

## Scope

State-shaped execution remains a technology preview. This release does not
promote it to the primary operator work-surface. Cross-platform GitHub Actions
CI now mirrors the routine checks; this cut uses the local release gate.
Package publication, binary distribution, and signing remain outside the tagged
release process. The package metadata version remains independent of release tags.
