# TOAS 0.0.2.0

Release date: 2026-08-17

## Summary

This release advances TOAS from the `0.0.1.0` history/projection checkpoint
to a broader operator-runtime checkpoint. It delivers durable compaction and
session rotation, a clearer boundary between direct user intent and
model-addressable execution, resilient async host/Vim streaming, and
operator-visible activity health.

## Highlights

- Added LLM-native compaction projections, durable procedure state, and
  successor-session rotation so a compacted transcript can continue without
  rewriting prior durable history.
- Added automatic hot-journal rollover, with explicit recovery and
  anti-thrashing behavior, to keep active history manageable while preserving
  the append-only record.
- Added activity-health snapshots, tunable idle policy, bounded transition
  summaries, host observer metrics, and Vim timeout reporting for long-running
  async operations.
- Strengthened the Vim host integration with canonical transcript
  finalization, resubscription recovery, child-scoped tool completion, real
  host smoke coverage, and transcript syntax highlighting.
- Improved callable/tool ergonomics with YAML-literal salvage, adjacent-plan
  coalescing, safer file-write newline handling, explicit assistant execution
  timeouts, and overwrite-safety hardening.

## Notable Fixes

- Preserved append-only successor continuation and compact handoff output
  instead of replacing transcript content.
- Made typed-stream answer recovery and completed shell-failure projection
  terminal and visible to operators.
- Hardened cancellation, watch, and local-host reconciliation against delayed
  frames, stale fallbacks, duplicate chunks, and terminal races.
- Kept quoted frontiers inert and tightened callable/frontier detection so
  execution remains explicit.

## Deferred

- Package publication, distribution channels, signing, and hosted CI remain
  outside the current lightweight tagged-release process.
- The open session-identity, multi-operator, tool-intent-ingress, activity
  health, and transcript-highlighting design tasks remain follow-on work;
  their presence is not a known regression in this stable checkpoint.
